\begin{center}
{\Large {\bf \uppercase{Abstract}}}
\end{center}

\vspace{\baselineskip}
\hrule
\vspace{2\baselineskip}

Most story generators built on large language models take a single prompt and return a finished story, so the user must describe everything at the start and has little control afterwards. This dissertation presents an interactive storytelling system in which the story is built from the user's answers to a short set of questions on setting, character, theme and plot, and is then continued chapter by chapter in the direction the user chooses. The language model is Llama 3.2 3B, fine-tuned with QLoRA on 3,321 prompt and story pairs prepared from 1,000 public stories in the same format that the system uses, and it runs on an ordinary laptop without any external service. On 191 test samples from 49 stories that were not used in training, fine-tuning lowered the loss from 1.521 to 1.194 and the perplexity from 4.58 to 3.30 ($p < 0.001$). On 69 test prompts the fine-tuned model always returned only the story text, against 75\% for the original model, at the same speed of about 37 tokens per second, although its chapters were shorter than requested. An earlier user study of the system with 15 participants, carried out with a pretrained Llama model before fine-tuning, gave mean ratings of 4.05 for coherence, 4.12 for creativity, 4.35 for engagement and 3.75 for consistency on a five-point scale.

\vspace{2\baselineskip}
\textit{Keywords: Generative AI, Large Language Models, Llama, Fine-Tuning, LoRA, Interactive Storytelling, Question Answering, Local Inference.}
